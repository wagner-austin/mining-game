# W2 — Left nav; Inventory panel; filters + sticky Sell Bar

Links: coordination/REORG_2025-09-14.md | coordination/ENGINEERING_STANDARDS.md | coordination/workers/README.md

Objectives
- Introduce a left navigation pattern for the settings/collections UI.
- Enhance the Inventory panel with item filters and a sticky Sell Bar.

Deliverables
- Left nav skeleton (component or `TabContainer` variant) integrated in `SettingsPanel` under a feature flag.
- Inventory filters (type: resource/consumable/cosmetic; rarity; text) and quick toggles.
- Sticky Sell Bar pinned to the bottom: shows selected items total value and a “Sell” action.
- Wire Sell to `InventoryService.SellItems` via `ClientRF` with optimistic UI and error states.

Interfaces & Events
- RFs: `GetInventory`, `SellItems`, `EquipItem`, `UnequipItem` (Inventory.rf.lua).
- Events: `INVENTORY_DELTA`, `PROFILE_UPDATED`, `CURRENCY_CHANGED` (for coin updates).

Dependencies
- Theme components: `UI/Theme.lua`, `UIConstants.lua`.
- Data provider (if available) from Account layer; fallback to `PlayerProfileGuard` + `ClientRF`.

Acceptance Criteria
- Left nav works on Studio desktop and scales for smaller screens.
- Inventory filters update visible items without jank; state persists while panel open.
- Sell Bar remains visible while scrolling and prevents selling unsellable items (cosmetics/pickaxes).
- Clear errors for insufficient items; coin balance updates after successful sale.

Notes
- Coordinate layout with W5 (Cash Shop UI) so navigation patterns are consistent.
- Keep DOM churn low in Inventory (batch updates, reuse existing debounces in InventoryTab where possible).
