# W6 — QA checklist; notes

Links: coordination/REORG_2025-09-14.md | coordination/ENGINEERING_STANDARDS.md | coordination/workers/README.md

Objectives
- Provide a clear, repeatable QA checklist covering core flows for Phase 1.

Deliverables
- Test plan sections: Server RFs, UI (Shop/Inventory), Currency/Inventory integrity, Feature flags, Rate limits, Error handling.
- Triage notes template and a lightweight bug log format.

Checklist (initial)
- Shop RFs
  - GetShopCatalog: returns items, prices, respects feature flags and filters.
  - PurchaseItem: success path (affordable); failure paths (`INSUFFICIENT_FUNDS`, `ITEM_NOT_FOUND`, disabled flag).
  - Rate limit respected; repeated calls do not double‑spend.
- UI
  - Left nav renders; Shop tab respects `SHOW_SHOP_TAB`.
  - Inventory filters behave; sticky Sell Bar works; cannot sell unsellables.
  - Robux purchase prompts fire (Studio stub acceptable), no crashes.
- Integrity
  - Coins never negative; inventory counts stable; saves queued.
  - Events: `CURRENCY_CHANGED`, `INVENTORY_DELTA` observed on client.
- Flags
  - Toggling features hides UI and disables RFs with `NOT_AVAILABLE`.

Notes
- Record repro steps, expected vs actual, and attach minimal logs (service + RF names, error codes).
