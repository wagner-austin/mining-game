# W3 — Shop RF (WS-021) — List/Buy, affordability, grant, rate limits

Links: coordination/REORG_2025-09-14.md | coordination/ENGINEERING_STANDARDS.md | coordination/workers/README.md

Role
- Backend RF/Catalog for Shop (coins + cosmetics), server-authoritative.

Objectives
- Provide Shop RFs to list purchasable cosmetics and process coin purchases.

Deliverables
- `server/MiningGame/RemoteFns/Shop.rf.lua` with:
  - `GetShopCatalog(category?: string, rarity?: string)` — returns cosmetics with coin prices.
  - `PurchaseItem(itemId: string, quantity?: number=1)` — affordability check, coin deduction, grant via `InventoryService`.
- Rate limits: 0.2s per call; robust validation and standard error codes.
- Emit events for UI: currency/inventory/notifications; auto‑equip on empty slot.
- Spec doc: `coordination/specs/WS-021_SHOP_RF.md` (request/response, errors, examples).

Decisions (Confirmed)
- Pricing = flat `CosmeticDefinitions.ITEMS[id].value` (coins).
- Auto‑equip on purchase if the target slot is empty; otherwise return `equipSuggested = true`.
- Exclude `slot == "modelSwap"` from catalog.
- Allow duplicate purchases (stackable cosmetics in inventory).

Interfaces & Events
- Services: `CurrencyService` (canAfford/add), `InventoryService` (AddItem/EquipItem), `DataService` (QueueSave).
- Events: `CURRENCY_CHANGED`, `INVENTORY_DELTA`/`INVENTORY_CHANGED`, `NOTIFICATION_PUSH`, `EQUIPMENT_CHANGED` (if auto‑equipped).

Flags & Limits
- Feature flags: server gate `SHOP_ENABLED` (RF availability); UI gate `SHOW_SHOP_TAB` (panel visibility).
- Rate limit: 0.2s per RF call.

Catalog Organization (Server)
- Filters: `category` (slot) and `rarity`.
- Sorting: notOwned → rarity (MYTHIC→COMMON) → price asc → name asc.
- Featured (optional): curated IDs first if configured; else sorting fallback.

Acceptance Criteria
- Catalog lists only allowed items with server‑auth prices.
- Purchase path: no negative coins, item granted, save queued, relevant events emitted.
- Error codes: `INVALID_INPUT`, `ITEM_NOT_FOUND`, `NOT_AVAILABLE`, `INSUFFICIENT_FUNDS`.
