# W5 — Cash Shop UI; Item Index UI

Links: coordination/REORG_2025-09-14.md | coordination/ENGINEERING_STANDARDS.md

Manager Decision (2025-09-14)
- Use Shop RF names: `Shop.GetShopCatalog` and `Shop.PurchaseItem`.
- Gate Cosmetics tab behind `GameConfig.Features.SHOW_SHOP_TAB` and only show when Shop RF is live.
- Robux/Coins remain active via Monetization RFs.

Objectives
- Build the in-game Shop UI (coins + Robux) and an Item Index browser using existing UI patterns.

Deliverables
- CashShopPanel (`client/MiningGame/UI/Panels/CashShopPanel.lua`):
  - Coins: `Monetization.GetPrices` + `PurchaseProduct` with success/error toasts.
  - Cosmetics: `Shop.GetShopCatalog` + `Shop.PurchaseItem` when feature-enabled; hide tab when `SHOW_SHOP_TAB == false`.
  - Affordability states, button debouncing, rarity accents, error toasts/banners, success toasts.
- ItemIndexPanel (`client/MiningGame/UI/Panels/ItemIndexPanel.lua`):
  - Aggregate from `GameConfig.Loot.ITEMS` + `CosmeticDefinitions.ITEMS` at runtime; filters (Type, Rarity, Enhanced), search, item detail.
- Integrate with W2 left-nav; respect `GameConfig.Features.SHOW_SHOP_TAB` gating.

Interfaces & Events
- RFs: `Shop.GetShopCatalog`, `Shop.PurchaseItem`, `Monetization.GetPrices`, `Monetization.PurchaseProduct`, `Monetization.PurchaseGamepass`.
- Events: `CURRENCY_CHANGED`, `INVENTORY_DELTA`.

Dependencies
- UI components: `BasePanel`, `TabbedPanel`, `BaseChip`, `UIUtils`, `Theme`.
- Shared list UI: `SimpleList` (used by both panels).

Acceptance Criteria
- Catalog lists purchasable cosmetics; affordability and buy flows work; toasts show success/errors.
- Item Index lists without hardcoding; filters/search responsive; detail opens.

Landed
- CashShopPanel implemented (TabbedPanel with Coins and Cosmetics):
  - Coins: `Monetization.GetPrices` + `PurchaseProduct` with success/error toasts.
  - Cosmetics: Uses `Shop.GetShopCatalog` when present; falls back to `CosmeticDefinitions` when RF missing and disables Buy. Sorted by rarity/price; affordability-aware; Buy debounced; rarity accents. Tab is gated by `SHOW_SHOP_TAB` and is hidden when the flag is false.
  - UX polish: loading rows, empty states, and retry rows for price/catalog fetch; right-side price meta label on rows.
- ItemIndexPanel implemented:
  - Aggregates from `GameConfig.Loot.ITEMS` + `CosmeticDefinitions.ITEMS`; filters (Type/Rarity/Enhanced), search; detail card with type/slot/value and baseline note; empty state when filters return no items.
- DRY list UI: added `SimpleList` component used by both panels.
- Feature flag added: `GameConfig.Features.SHOW_SHOP_TAB`.

Gaps
- Detail pane polish (optional): cosmetic effect/notes; owned/equipped indicators when data available.
