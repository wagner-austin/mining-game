What’s Shipped (Code)
- Server
  - `server/MiningGame/InventoryService.lua`: `_recomputeCosmeticPerks` aggregates perks only from `def.enhanced == true`, respects `ENHANCED_PERKS_ENABLED`, and applies CharacterStateManager effects:
    - Speed: `cosmetic_speed_105/110/115` (exclusive tier)
    - Extra jumps: `cosmetic_extra_jumps_1..4` (exclusive tier) or legacy `cosmetic_triple_jump`
  - DI: `CharacterStateManager` resolved via `ServiceValidator.tryGet` in `Init` and refreshed in `Start`.
- Effects Catalog
  - `shared/MiningGame/Character/Effects.lua`: defines speed and extra-jump tiers (+ legacy triple) with movement fields where appropriate.
- Client
  - `character/Movement/DoubleJump.client.lua`: reads CharacterStateClient effects; computes total jumps as `base + tier`.
  - `character/Movement/ApplyStats.client.lua`: movement scalars from effects (no attribute trust).
- Visuals
  - `client/MiningGame/Cosmetics/Renderers/Back.lua`: supports per-item `animSpec` (speedHz/freqHz, amplitudeDeg, axis, c0) for flapping.
- Definitions
  - `shared/MiningGame/CosmeticDefinitions.lua`:
    - Added `back_quad_wings` (LEGENDARY, enhanced = true, `perks = { extraJumps = 2 }`, value = 3000).

    - Legacy wings retain only `animSpec` (perks removed) to avoid unintended perks.

- `GameConfig.Features.ENHANCED_PERKS_ENABLED` gates server perk application (clears effects when off).
- InventoryService aggregates perks only from enhanced items.
